# AI Club pass assets

`ai-club-pass.glb` is original geometry generated for this project by
`scripts/build-event-badge.mjs`. It includes a bevelled laminated shell with a
real attachment slot, reinforced metal eyelet, swivel clip, ring and two rivets.
The source script is the editable model source; Blender is not installed here.
It is not a recreation or redistribution of Vercel's Blender file.

`fabric.svg` is an original woven pattern. Its white/grey texels are tinted at
runtime using the site's existing CSS palette. No Vercel runtime assets are used.

The Vercel article's final source was studied for mechanics and material setup.
No explicit asset-reuse licence was found in that article, so its demonstration
GLB, photographs and band texture were not copied. These original assets follow
the repository's own licensing terms; this file grants no rights to club branding.
